# Read reef notes

Open factual sources, context and interaction guidance without covering the scene by default.

## Sub-features

Open/close; Escape; sources; phone fit.

## How to get to it (user POV)

Choose About this reef in the upper corner.

## Driving it with Playwright

Preconditions: the correct Reef page has loaded with WebGL working.

Run `npm run verify`. It clicks the named control, requires a visible dialog, presses Escape and requires the dialog hidden. Inspect notes at 390px and check source links.

## Gotchas

Do not turn the notes into default scene furniture. Notes are the place for interpretation limits and accessibility guidance.
