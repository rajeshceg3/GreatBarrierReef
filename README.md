# Great Barrier Reef

An original, procedural 360-degree underwater world. Four connected imagined habitats: a sunlit coral garden, turtle passage, the outer edge, and a spawning night.

Open `index.html` through any static HTTP server. No build step. Three.js is vendored locally (MIT license). Fonts have system-serif/sans fallbacks. No analytics, accounts, images or external runtime scripts.

## Interaction

- Drag the scene or use arrow keys to look around.
- Choose a habitat with the visible navigation, or swipe within the navigation strip only.
- Tap a creature or use each habitat's encounter control to discover its ecology.
- Ambient motion can be paused. Reduced-motion users begin paused.
- Sound is optional and synthesized locally. It starts only after an explicit tap.

This is an artistic interpretation, not a reef-condition report, dive map or species-identification guide. In-scene depths are compositional settings. Ecology sources are linked in the notes: Reef Authority biodiversity, coral spawning, and herbivorous-fish guidance.
